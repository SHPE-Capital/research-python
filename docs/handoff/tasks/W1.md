## Goal

Participants plant three kinds of leakage in a pipeline, watch each inflate
the result, and then catch each one with the repo's checks.

## Interface

Helpers defined in the notebook (not in `src/`), so the library never ships a
leaky feature:

| Helper | Leak |
|---|---|
| `CenteredMean` | Rolling mean centred on t (uses future bars) |
| `DayZScore` | Z-score with the whole session's mean and std |
| `NextReturn` | The label shifted into the features |

Exercises: compute the inflated metric for each, then make `check_feature`
(or the truncation test) fail on each and pass on the fix.

## Behaviour

- Runs on the default fixture (`synthetic_bars()`, `signal_strength` 0.3) and
  on a frozen D5 snapshot when real data is enabled.
- `configs/clean.yaml` is the baseline; `leaky_feature.yaml` swaps in a helper.
- C1f and C1m are not required; the purged-split exercise is an optional
  extension that runs only if C1f is merged.
