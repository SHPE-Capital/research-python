## Goal

Give every team the same three diagnostics for choosing holding period, stop,
target and parameters, all computed on a `TradeLedger` or on bars and
candidates, and all honest about how many configurations were tried.

## Interface

| Function | Module | Returns |
|---|---|---|
| `holding_curve(bars, candidates, horizons, cost_model=None, n_boot=1000, block=None)` | `holding.py` | Frame: horizon, mean net return, `low`, `high` (block bootstrap), n |
| `ou_half_life(series)` | `holding.py` | Half-life in bars from an AR(1) fit on the level; `inf` if the slope is ≥ 0 |
| `excursions(ledger, bars)` | `excursions.py` | Ledger plus `mfe`, `mae` (in return and in R if `stop_price` exists) |
| `stop_target_curves(bars, candidates, stops, targets, base_policy)` | `excursions.py` | Grid of net expectancy and hit rates per (stop, target) |
| `parameter_surface(run_fn, grid)` | `surfaces.py` | Frame of metric per grid point, plus `n_trials`, `deflated_sharpe` of the best point, and a plateau score |

## Behaviour

- `holding_curve` exits each candidate after h bars with `simulate_trades` and
  `max_hold_bars = h` (signal exit at next open), so costs and fills are T1's.
- The bootstrap block length defaults to the largest horizon.
- `stop_target_curves` runs T1 for each grid point; it does not re-implement fills.
- `parameter_surface` always reports `n_trials` and the deflated Sharpe of the
  best point (E2). The plateau score is the median metric of the best point's
  neighbours divided by the best point's metric; a lone peak scores low.
- Everything is seeded and deterministic.
