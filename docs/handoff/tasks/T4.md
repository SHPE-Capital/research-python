# T4: Risk limits

| Wave | Level | Depends on | Blocks | Agent |
|---|---|---|---|---|
| 1 | Int | C1a | T7, W8, W9 | `strategy-builder` (review: `platform-parity`) |

## Goal

Reject or accept each order with the platform's risk checks, in the platform's
order and with the platform's reason codes, so a research backtest and a
platform backtest refuse the same trades.

## Owns (exclusive)

- `src/shpe_research/trade/risk.py`
- `RiskLimits` fields in `src/shpe_research/trade/types.py`
- `tests/unit/trade/test_risk.py`

## Reads

- [design/trade-layer.md](../../design/trade-layer.md) (Risk)
- Platform: `backend/src/core/risk/riskEngine.ts`, `types/risk.ts`,
  `docs/architecture/risk-layer.md`

## Interface

`RiskLimits` fields (snake_case of `RiskConfig` and `StrategyRiskBudget`):
`max_position_size_usd`, `max_notional_exposure_usd`, `order_cooldown_ms`,
`stale_quote_threshold_ms`, `allow_short_selling`, `max_intraday_drawdown_pct`,
`max_concentration_pct`, `cash_reserve_pct`, `max_gross_exposure_pct`,
`max_net_exposure_pct`, `strategy_max_capital_pct`,
`strategy_max_order_notional_pct`, `strategy_max_open_orders`, plus the
research-only `max_concurrent_same_side` and `initial_equity`.

`check_order(order, portfolio, limits) -> RiskDecision(accepted, reason)`;
`check_portfolio(portfolio, limits, ts) -> list[RiskDecision]`.

Reason codes in check order (first failure wins):

`KILL_SWITCH`, `MARKET_CLOSED`, `STALE_QUOTE`, `ORDER_COOLDOWN`,
`MAX_POSITION_SIZE`, `MAX_NOTIONAL_EXPOSURE`, `SHORT_SELLING_DISALLOWED`,
`CASH_RESERVE`, `INTRADAY_DRAWDOWN`, `CONCENTRATION_LIMIT`, `STRATEGY_BUDGET`,
`STRATEGY_ORDER_NOTIONAL`, `MAX_OPEN_ORDERS`, then research-only
`MAX_CONCURRENT_SAME_SIDE`.

## Behaviour

- `KILL_SWITCH` and `STALE_QUOTE` always pass on historical bars; they stay in
  the list so codes line up.
- `MARKET_CLOSED` uses the regular session (09:30–16:00 New York, early closes
  from the calendar).
- Portfolio checks (gross, net, drawdown) run once per bar, like the
  platform's `checkPortfolio()`.
- `max_concurrent_same_side` caps open positions with the same side across
  symbols for one strategy (SM1 ORB on correlated names). It is not exportable;
  T7 refuses it by name until a platform field exists.
- `initial_equity` has no platform field; T7 maps it to the backtest's
  starting cash and records the mapping.
- Rejected orders appear in the ledger as `unfilled` with `risk_reason`.

## Acceptance tests

| Path | Test | Asserts |
|---|---|---|
| `tests/unit/trade/test_risk.py` | `test_reason_order` | An order failing three checks returns the earliest code in the list |
| | `test_kill_switch_and_stale_pass` | Both always accept in research |
| | `test_short_disallowed` | Short with `allow_short_selling=False` → `SHORT_SELLING_DISALLOWED` |
| | `test_cooldown` | Second order within `order_cooldown_ms` → `ORDER_COOLDOWN` |

| | `test_names_match_platform` | Every field maps to a platform name in a table in the module |

## Out of scope

Sizing (T2), exporting limits (T7), the kill switch itself.

## Done when

Tests pass and `simulate_trades(..., risk=RiskLimits(...))` rejects with reasons.
