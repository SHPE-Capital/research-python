## Goal

F8: the benchmark's return since the session open at decision time, plus a
rolling β and the residual return. F7: the pair spread z-score, hedge ratio
and half-life, computed with the same estimators the stat-arb team uses and
the same definitions as the platform.

## Behaviour

- F8 `market_return`: latest completed benchmark close available at the
  decision bar's `ts_available`, divided by the benchmark's session open,
  minus 1. Context alignment goes through `align_context`; a benchmark bar is
  used only if its `ts_available` ≤ the row's `ts_available`. A missing
  benchmark bar gives NaN, never a forward fill across a gap.
- F8 `market_beta`: OLS slope of the symbol's 1-bar returns on the
  benchmark's over the previous `window_bars` bars, excluding the current
  bar; the residual is this bar's return minus β times the benchmark's. SR3
  and W8 use these columns.
- F7: hedge ratio from `pair_math.hedge_ratio(..., method=hedge)`, spread
  `p − β·p_other`, z-score from `pair_math.spread_zscore`, half-life from
  `pair_math.fit_ou`, all on data before the decision bar.
- **Price space.** The existing stub docstring describes log-price OLS with
  an intercept. The platform uses raw prices and no intercept
  (`spread = p1 − β·p2`). The default is `price_space: raw` to match the
  platform; `log` is available for research and is marked not exportable
  until P9 adds `priceSpace`. Delete the stub's log-price description.
- Both features are registered only for rows whose symbol is not a context
  symbol (C1d guarantees context symbols never appear as dataset rows).
