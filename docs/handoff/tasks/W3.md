## Goal

Build a daily cross-sectional ranker: combine a short-term reversal score and
a 12-1 momentum score, equally, by ridge, and by LightGBM, and judge them by
rank IC and long-short portfolio returns.

## Interface

`str.yaml` and `mom.yaml` use `identity` on one feature each (short-term
reversal, `momentum_12_1`). `combine_eq` averages their ranks. `combine_ridge`
uses `ridge_reg` on the rank-transformed features. `combine_lgbm` uses
`lightgbm_reg` (M1b). All use `data.frequency: daily` and
`synthetic_bars(daily={"years": 3, "n_symbols": 50, "xs_momentum": ...})`.

## Behaviour

- Features rank-transformed per `decision_ts` (C1d).
- Labels are next-period returns from `session_close` events (C1b).
- `ridge` (classifier) and `ridge_reg` (regressor) wrap scikit-learn with a
  standardiser and follow the M-series model contract.
