## Goal

Set up the shared pieces every workshop example uses: the folder layout, the
`workshop` dependency group, notebook conventions, the test harness that runs
each example on fixtures, and the pass bands those tests check.

## Owns (exclusive)

- `workshop/README.md`, `workshop/_common/` (plotting and display helpers only)
- `pyproject.toml`: the `workshop` dependency group (jupytext, jupyterlab) only
- `tests/workshop/conftest.py`, `tests/workshop/bands.py`
- `tests/workshop/test_00_harness.py`
- The `workshop-solutions` branch convention (documented in `workshop/README.md`)

## Interface

Folder layout, one per example:

```
workshop/NN_slug/
  README.md          # learning goals, run commands, exercise list
  notebook.py        # jupytext percent format
  exercises.py       # functions participants fill in (raise NotImplementedError)
  configs/*.yaml     # ExperimentConfig / StrategySpec files
```

Solutions live on the `workshop-solutions` branch at the same paths
(`exercises.py` filled in). Tests: `tests/workshop/test_NN_slug.py`.

`bands.py`: `Band(metric, low, high, seeds)` and `assert_in_band(fn, band)`,
which runs `fn(seed)` for each seed (default 5 seeds) and checks every result
is in `[low, high]`, reporting all values on failure.

Marks: `@pytest.mark.workshop` on every example test; `slow` on tests over 60
seconds. Each example test must finish in under 5 minutes on a laptop.

## Behaviour

- Notebooks run top to bottom with fixtures only (no API keys); a cell that
  needs real data is guarded by `SHPE_WORKSHOP_REAL_DATA=1`.
- The harness runs `notebook.py` as a script with `exercises.py` swapped for
  the solution module when `SHPE_WORKSHOP_SOLUTIONS` points at it, so CI on
  the solutions branch checks the full path.
- Pass bands come from several seeds, not one lucky seed.

## Acceptance tests

| Path | Test | Asserts |
|---|---|---|
| `tests/workshop/test_00_harness.py` | `test_band_all_seeds` | A band fails if any one seed is outside it, and the message lists every seed's value |
| | `test_notebook_runs_as_script` | A toy `notebook.py` runs with the stub and with a solution module |
| | `test_real_data_guard` | Guarded cells are skipped without the env var |
