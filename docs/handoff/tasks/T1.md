## Goal

One simulator turns candidates and bars into a `TradeLedger` using the
platform's bar fill rules. Labels (C1c `triple_barrier`), backtests and the
parity check (T7) all call it, so exit logic exists once. T1 absorbs the old
L2 stub `labels/exit_policy.py`; [L2](L2.md) then reduces that file to a shim.

## Interface

`FillModel` (frozen dataclass; defaults equal the platform's `DEFAULT_FILL_MODEL`):

| Field | Default | Platform name |
|---|---|---|
| `half_spread_bps` | 2.0 | `halfSpreadBps` |
| `slippage_bps` | 5.0 | `slippageBps` |
| `commission_per_share` | 0.005 | `commissionPerShare` |
| `volume_participation_cap` | 0.1 | `volumeParticipationCap` |
| `allow_partial_fills` | True | `allowPartialFills` |
| `price_source` | `next_open` | `priceSource` (ignored by the platform since v5; kept for the record) |
| `engine_version` | 2 | `BACKTEST_ENGINE_VERSION` |

The L2 stub's defaults (1, 2, 0) and additive formula are wrong; T1 replaces them.

`ExitPolicy` (frozen dataclass):

| Field | Values | Meaning |
|---|---|---|
| `stop_rule` | `none` \| `pct` \| `atr` \| `price` | `price` uses the candidate's `stop_price` (SM1 writes range-mid or range-low there) |
| `stop_pct`, `stop_atr_mult`, `atr_window` | float, float, int (14) | Stop distance |
| `target_rule` | `none` \| `pct` \| `price` \| `r_multiple` | `r_multiple`: entry ± `target_r` × initial risk (entry − stop) |
| `target_pct`, `target_r` | float | Target distance |
| `trail_rule` | `none` \| `chandelier` \| `breakeven_1r` | See Behaviour |
| `trail_atr_mult` | float (3.0) | k for the chandelier stop |
| `max_hold_bars` | int or None | Signal exit after this many bars |
| `session_end` | bool (True) | Flatten at the last regular bar; must be False for parity runs of `minute_reversal` and `pairs_trading` |
| `flat_by` | `HH:MM` or None | Signal exit at this New York time |
| `use_signal_exits` | bool (True) | Consume `action = exit` candidate rows |
| `entry_order` | `market` \| `stop` | `stop`: a buy stop at the candidate's `entry_price` (e.g. the opening-range high), expiring at 16:00 New York (DAY) |

`simulate_trades(bars, candidates, policy, fill=FillModel(), costs=None,
sizing=None, risk=None) -> TradeLedger`. `costs` defaults to
`CostModel.from_fill(fill)` (T5; until T5 merges, T1 computes cost from `fill`
directly). `sizing` and `risk` are applied when given (T2, T4); otherwise
`qty` comes from the candidate or 1.

`TradeLedger` columns: `symbol`, `strategy_id`, `side`, `decision_ts`,
`entry_ts`, `entry_price`, `qty`, `exit_ts`, `exit_price`, `exit_reason`,
`gross_return`, `cost`, `net_return`, `label_end_ts` (= `exit_ts`), optional
`mfe`, `mae`, `partial_fill`, `early_close`. A pair is one trade; per-leg
prices go in `leg2_*` extras.

## Behaviour

Fills (platform bar model, `BACKTEST_ENGINE_VERSION` 2):

- The fill bar is the first bar with `ts >= decision_ts`. A missing minute means the next bar that exists.
- Market buy price = `open × (1 + hs/1e4) × (1 + slip/1e4)`; sell = `open × (1 − hs/1e4) × (1 − slip/1e4)`.
- Zero volume: no fill; an entry gets `exit_reason = unfilled`. Volume cap 0.1 of
  bar volume; partial fills reduce `qty` and set `partial_fill`.
- Stop and target orders are checked on bars after the entry fill bar (the
  entry bar is excluded, matching the platform's "bar ending after the order
  was placed"; T7's goldens confirm this), regular session only.
- Buy stop (entry or short cover) triggers when `high >= stop` and fills from
  `max(open, stop)`; sell stop (long protective stop) triggers when
  `low <= stop` and fills from `min(open, stop)`. The trigger price then gets
  spread and slippage like a market order.
- Targets touch-check like the platform's limit model; a target hit fills at
  the target (or the gap open if better), costed like a market order.
- Stop and target in the same bar: the stop fills first.
- DAY orders expire at 16:00 New York. On early-close sessions there are no
  bars after 13:00, so a resting stop stops being checked; the trade is flagged
  `early_close`.

Exits:

- Order exits (price stop, target, trailing stop) fill intrabar. Signal exits
  (`action = exit` rows, `max_hold_bars`, `flat_by`, `session_end`) fill at the
  next bar's open.
- Chandelier trailing stop: highest high since entry − `trail_atr_mult` × ATR,
  both from completed bars only; the level updates at each bar's end and
  applies from the next bar; it never loosens.
- `breakeven_1r`: once the price has moved 1R in favour (on a completed bar),
  the stop moves to the entry price.
- Priority when several fire at one decision time: `stop_loss`, then
  `max_hold_exit`, then `exit`. `session_end` is research-only.
- `exit_reason` values: `stop_loss`, `take_profit`, `exit`, `max_hold_exit`,
  `session_end`, `unfilled`. The old L2 names `stop`, `target`, `time` are gone.
- `cost` includes commission; `gross_return` excludes all costs; `net_return`
  = gross minus cost over entry notional.
- One open position per `(symbol, strategy_id)`; an entry while open is ignored
  unless the candidate's `side` is opposite and the strategy flips (SR1).
