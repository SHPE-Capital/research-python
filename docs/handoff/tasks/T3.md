# T3: Entry filters

| Wave | Level | Depends on | Blocks | Agent |
|---|---|---|---|---|
| 1 | Beg–Int | C1a | SM1, SR2, W4 (optional), W9 | `strategy-builder` (review: `leakage-auditor`) |

## Goal

Drop candidates a strategy should not take, with a recorded reason per row, so
studies can report what each filter removed and what it cost.

## Owns (exclusive)

- `src/shpe_research/trade/filters.py`
- `tests/unit/trade/test_filters.py`

## Reads

- [design/trade-layer.md](../../design/trade-layer.md) (Filters and costs)
- `src/shpe_research/contracts/candidates.py`

## Interface

`@register_filter` keyed on `filter_type`; `apply_filters(candidates, frame,
filters) -> (keep: pd.Series[bool], skip_reason: pd.Series[str])`. `frame` holds
the candidate rows joined to precomputed feature columns.

| Key | Params | Skips when |
|---|---|---|
| `time_window` | `start`, `end` (New York) | Decision outside the window |
| `min_liquidity` | `column`, `min` | Dollar volume or ADV below `min` |
| `max_spread` | `column`, `max_bps` | Quoted spread wider than `max_bps` |
| `regime` | `column`, `min`, `max` | Regime measure outside the band |
| `blackout` | `calendar` (`earnings`\|`fomc`\|path), `sessions_before`, `sessions_after` | Inside an event window |
| `min_rvol` | `column`, `min` | Relative volume below `min` (SM1, W4) |
| `meta_score` | `column`, `min_probability` | Meta-model probability below the threshold |

## Behaviour

- Filters read precomputed columns only; they never compute features (keeps
  `trade/` at rank 3).
- A missing column raises naming the filter and column.
- The first filter that fails sets `skip_reason`; later filters still run so
  the study can report overlap (`skip_reasons_all` as a list column).
- Blackout calendars use the date known at `decision_ts` (an earnings date
  announced after the decision does not count).
