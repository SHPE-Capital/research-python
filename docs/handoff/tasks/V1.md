## Goal

Return walk-forward folds where no training row's label interval overlaps
its fold's test interval, with an optional embargo after each test block.

## Interface

Unchanged from the stub:

```python
def purged_walk_forward(
    meta: pd.DataFrame,                 # decision_ts, label_end_ts (UTC ns)
    n_folds: int = 5,
    embargo: pd.Timedelta | None = None,  # None means zero
    expanding: bool = True,
) -> Iterator[tuple[np.ndarray, np.ndarray]]:   # (train_positions, test_positions)
```

## Behaviour

- Test blocks are contiguous in `decision_ts` and split the sorted rows into
  `n_folds + 1` blocks; fold k tests on block k+1 and trains on blocks before
  it (expanding) or the block immediately before it (`expanding=False`).
- Purge: drop training rows with `label_end_ts >= test_start` and
  `decision_ts <= test_end`, where `test_end` is the latest `label_end_ts` in
  the test block.
- Embargo: drop training rows whose `decision_ts` is within `embargo` after
  `test_end`. With walk-forward ordering this only matters when training data
  follows the test block; the parameter is kept so C1f can reuse it for
  combinatorial schemes later.
- Rows with missing `label_end_ts` raise `ValueError`; they are never silently
  treated as same-bar labels.
- Positions are into `meta` as passed (not its index labels).
