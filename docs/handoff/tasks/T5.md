# T5: Cost model

| Wave | Level | Depends on | Blocks | Agent |
|---|---|---|---|---|
| 1 (calibration after R5) | Int | C1a; R5 for the calibrated model | T7, W6, W7, W8, W9 | `trade-management-analyst` (review: `platform-parity`) |

## Goal

Express trading cost as one object used by the simulator and the trading
metrics, with a default equal to the platform bar model and a slot for the R5
calibration.

## Owns (exclusive)

- `src/shpe_research/trade/costs.py`
- `CostModel` fields in `src/shpe_research/trade/types.py`
- `tests/unit/trade/test_costs.py`

## Reads

- [design/trade-layer.md](../../design/trade-layer.md) (Filters and costs)
- `src/shpe_research/evaluation/trading.py` (turnover and cost-adjusted metrics)
- `studies/shared/r5-tca/` (when R5 reports)

## Interface

`CostModel` fields: `half_spread_bps=2.0`, `slippage_bps=5.0`,
`commission_per_share=0.005`, `impact_coef=0.0`, `impact_exponent=0.5`,
`source` (`platform_default`\|`calibrated:<run id>`).

- `CostModel.from_fill(fill: FillModel) -> CostModel`
- `cost(side, price, qty, adv=None) -> (cost_usd, cost_bps)`; impact term =
  `impact_coef × (qty / adv) ** impact_exponent` in bps when `adv` is given.
- `CostModel.from_tca(path) -> CostModel` reads an R5 result table.

## Behaviour

- The default reproduces the platform: spread and slippage are already in the
  fill price, so `cost` reports them for attribution and adds commission.
  `net_return` is not double-charged; a test checks it.
- Any result a team presents uses a calibrated model (`source` starts with
  `calibrated:`); reports print `source`.
