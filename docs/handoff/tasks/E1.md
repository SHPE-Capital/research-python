# E1: Trading metrics, split from T6

| Wave | Level | Depends on | Blocks | Agent |
|---|---|---|---|---|
| 1 | Int | C1a (report-section registry); L1 for `ic_decay` only | C1i, T6, W2, W3, every study report | `research-analyst` (review: `leakage-auditor`) |

The stub (`src/shpe_research/evaluation/trading.py`) and its test
(`tests/todo/test_eval_todo.py::test_trading_metrics`) exist. Two things
change. First, E1 measures **signals** (scores against forward returns) and
T6 measures **trades** (a `TradeLedger`); nothing in E1 reads a ledger.
Second, E1 does not edit `experiments/runner.py` (owned by C1a): it registers
a report section, and the runner writes it.

## Goal

Every report says whether a score is worth trading: how fast its edge decays,
how much it turns over, what survives costs, and whether a few names or
months drive it.

## Interface

```python
def trading_metrics(predictions: pd.DataFrame,
                    cost_bps: Sequence[float] = (0, 2, 5, 10),
                    horizons: Sequence[int] | None = None) -> dict: ...

@register_report_section
class TradingSection:              # pattern and base class from C1a
    section_type = "trading"
    # builds its dict by calling trading_metrics on the run's predictions
```

Returned keys:

| Key | Content |
|---|---|
| `ic_decay` | Mean daily rank IC per horizon in minutes (needs L1 label columns; absent with a note when they are missing) |
| `turnover` | Mean fraction of the top/bottom decile that changes between consecutive decision times |
| `cost_adjusted` | `{cost_bps: mean net return per decision}` for long top decile / short bottom decile, plus `breakeven_bps` |
| `by_group` | IC and mean return by `symbol`, by month and by D4 universe cell when the column exists |

## Behaviour

- Uses only `split == "validation"` or `"test"` rows the caller passes; it never
  selects splits itself.
- Costs are charged per side, both legs, on turnover, in bps of notional. The
  T5 `CostModel` is not used here, because E1 has no fills; the report states
  that these are signal-level costs.
- Days with fewer than 5 symbols are skipped for IC and counted in the output.
