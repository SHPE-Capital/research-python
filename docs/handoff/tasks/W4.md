## Goal

Train a model that decides which ORB breakouts to take, using triple-barrier
labels from the real exit policy, and compare four trade selectors (A–D) on
net expectancy after costs.

## Interface

| Config | Selector |
|---|---|
| `orb_a` | Take every SM1 breakout |
| `orb_b` | Rule filter (RVOL and time window, T3) |
| `orb_c` | Meta-model (logistic, M1a) on F1–F4, F8 features with `meta_score` threshold |
| `orb_d` | Meta-model (gradient boosting, M1c) with the same features |

Data: `synthetic_bars(orb_rvol=..., context_symbols=["SPY"])`.

## Behaviour

- Labels: `triple_barrier` (C1c) calling T1 with the same `ExitPolicy` the
  backtest uses, so label and P&L agree.
- Purged splits with the embargo at least the longest label.
- The held-out cell runs only with `SHPE_WORKSHOP_HELDOUT=1` and prints a
  warning that it may be run once.
- Expected outcome (hypothesis): on the `orb_rvol` fixture, `orb_c` and
  `orb_d` beat `orb_a` on net expectancy because the planted drift depends on RVOL.
