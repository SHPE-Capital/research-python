## Goal

Turn a candidate into a whole-share quantity with a named, configurable rule,
using the same floor-to-shares convention as the platform sizers.

## Owns (exclusive)

- `src/shpe_research/trade/sizing.py`
- `SizingRule` fields in `src/shpe_research/trade/types.py`
- `tests/unit/trade/test_sizing.py`

## Reads

- [design/trade-layer.md](../../design/trade-layer.md) (Sizing)

  `docs/architecture/position-sizing-layer.md`

## Interface

`SizingRule(rule, **params)`; `size(candidates, bars, equity) -> pd.Series[int]`.

| `rule` | Params | Qty | Exportable today |
|---|---|---|---|
| `fixed_qty` | `qty` | `qty` | Yes (`qtyPerTrade`) |
| `fixed_notional` | `notional_usd` | `floor(notional / price)` | Yes (`fixed_notional`, `tradeNotionalUsd`) |
| `risk_per_trade` | `risk_usd` or `risk_pct`, uses `stop_price` | `floor(risk / |entry − stop|)` | No (P6) |
| `inverse_vol` | `target_risk_usd`, `vol_column` | `floor(target / (price × vol))` | No (P6) |
| `prob_to_size` | `prob_column`, `min_prob`, `max_notional_usd` | Linear in (p − min_prob), 0 below `min_prob` | No |
| `kelly_fractional` | `fraction`, `prob_column`, `payoff_ratio`, `cap_notional_usd` | `fraction` × Kelly notional, capped | No (P6) |

`price` is the estimated entry price (the decision bar's close), matching the
platform's `estimatedPrice`.

## Behaviour

- Every rule floors to whole shares; a result ≤ 0 means no trade
  (`exit_reason = unfilled` with `skip_reason = size_zero` in T3's terms).
- Rules read only columns known at `decision_ts`.
- A candidate's own `qty` (SR1, SS4) wins when `rule` is `native`.
- Each rule records `exportable: bool`; T7 refuses non-exportable rules by name.
