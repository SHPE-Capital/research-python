## Goal

Turn per-symbol scores at each decision time into target weights, with optional
neutralisation and turnover control, so cross-sectional strategies (SM3, W8)
are judged as portfolios with costs rather than as rank correlations.

## Interface

Config block (validated by C1h):

```yaml
portfolio:
  scheme: top_k            # top_k | rank | zscore | vol_scaled
  top_k: 10
  neutralize: [beta, sector]
  neutralize_proportion: 1.0
  gross: 1.0
  turnover:
    no_trade_band: 0.0     # skip a trade if |target - current| < band
    partial_adjustment: 1.0 # move this fraction toward target each rebalance
```

| Function | Returns |
|---|---|
| `scores_to_weights(scores, scheme, gross, top_k=None, vol=None)` | Weights per `(decision_ts, symbol)`, dollar-neutral, sum of `|w|` = `gross` |
| `neutralize_weights(weights, exposures, proportion)` | Calls C1d `neutralize`, then rescales to `gross` |
| `rebalance(target, current, no_trade_band, partial_adjustment)` | New weights and per-symbol trades |
| `portfolio_returns(weights, bars, cost_model)` | Frame: gross return, cost, net return, turnover per period |

## Behaviour

- `top_k`: equal long top k, equal short bottom k. `rank`: weights linear in
  centred rank. `zscore`: weights proportional to cross-sectional z-score.
  `vol_scaled`: any scheme then divided by the `vol` column, rescaled.
- Weights at `decision_ts` earn returns from the next bar's open (same timing
  as T1 signal exits), so there is no same-bar lookahead.
- Turnover = sum of `|Δw|` / 2 per rebalance; cost uses T5 on the traded notional.
- Symbols with a missing score get weight 0 and are reported.
